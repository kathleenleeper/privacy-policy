# Privacy policy: Personal scripts

Effective 261010 (Sat).

## Who uses the app

One person runs this app: the developer. It is a set of personal command-line scripts. No one else signs in to it, and it is not offered to the public.

## Where the app runs

The scripts run only on the developer's own computer. The app has no server, website backend or database.

## What Google data the app uses

The app asks Google for access to:

| Google service | Access | What the scripts do with it |
|---|---|---|
| Drive | Full Drive access | List folders and sharing settings, copy files, upload Markdown as Google Docs, move files to Trash |
| Sheets | Read and edit | Read ranges, write ranges, format cells |
| Docs | Read and edit | Read a document's text and structure, fix formatting |
| Slides | Read and edit | Read decks, audit style, apply layout and image changes |
| Gmail | Compose (drafts) | Create and update email drafts. Sending stays a manual step in Gmail. |
| Calendar | Read events, edit events | Read upcoming events, add planned work blocks to one named calendar |
| Forms | Edit forms, read responses | Build rating forms and read their responses |

The scripts act only when the developer runs them, on files and calendars in the developer's own Google account.

## Where the data goes

- Sign-in tokens are saved as files on the developer's computer, readable only by the developer's user account.
- Data read from Google is shown in the terminal or saved to files on that computer.
- Changes are written back only to the developer's own Google account.
- The app does not send Google data to any other person, company or service.
- The app does not sell data, use it for advertising, or use it to train models.

## Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access and data

The app's access can be removed at any time at https://myaccount.google.com/permissions. Deleting the token files on the computer removes the saved sign-in.

## Changes

Changes to this policy are posted at this address with a new effective date.
